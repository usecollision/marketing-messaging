# marketing-messaging

The **create** layer of the UseCollision Marketing OS. Everything that turns strategy and research into words: copy for any surface, complete landing pages, and content strategy.

Merged from: `marketing-copy` + `marketing-content` (Aug 2026).

## Skills

| Skill | Category | What it does |
|---|---|---|
| [conversion-copywriting](conversion-copywriting/SKILL.md) | copy | Write high-converting copy for any marketing surface using research-backed frameworks and customer language. |
| [landing-page-copy](landing-page-copy/SKILL.md) | copy | Write complete landing page copy with hero, features, social proof, objection handling, and CTA sections. |
| [content-strategy](content-strategy/SKILL.md) | content | Build a content strategy that drives organic traffic, builds authority, and converts readers to customers. |
