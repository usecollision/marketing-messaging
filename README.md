# marketing-messaging

The **create** layer of the UseCollision Marketing OS. Everything that turns strategy and research into words: copy for any surface, complete landing pages, and content strategy.

Merged from: `marketing-copy` + `marketing-content` (Aug 2026).

## Skills

| Skill | Category | What it does |
|---|---|---|
| [conversion-copywriting](conversion-copywriting/SKILL.md) | copy | Write high-converting copy for any marketing surface using research-backed frameworks and customer language. |
| [landing-page-copy](landing-page-copy/SKILL.md) | copy | Write complete landing page copy with hero, features, social proof, objection handling, and CTA sections. |
| [content-strategy](content-strategy/SKILL.md) | content | Build a content strategy that drives organic traffic, builds authority, and converts readers to customers. |
| [brand-voice](brand-voice/SKILL.md) | voice | Define brand voice and tone from customer language and founder voice, producing a voice guide teams can actually write with. |
| [value-proposition](value-proposition/SKILL.md) | strategy | Design a JTBD-based value proposition: quantified outcomes, uniqueness, and a defensible USP statement. |
| [messaging-hierarchy](messaging-hierarchy/SKILL.md) | strategy | Build a messaging architecture: positioning statement, value pillars, proof points, and taglines that cascade to every surface. |
| [customer-language-bank](customer-language-bank/SKILL.md) | research | Extract exact customer phrases from interviews and reviews and organize them by stage and pain into a reusable language bank. |
| [objection-handling](objection-handling/SKILL.md) | copy | Mine objections from research, write rebuttals with a proven formula, and place pre-emptive copy across every surface. |
| [email-copy](email-copy/SKILL.md) | copy | Write lifecycle and marketing email copy: subject lines, preview text, body structure, and CTAs that get opened and clicked. |
| [case-study-builder](case-study-builder/SKILL.md) | content | Build metrics-first case studies: challenge-solution-results structure, quantified outcomes, and repurposed variants for every channel. |
| [sales-deck](sales-deck/SKILL.md) | content | Write pitch deck copy slide by slide: problem-solution-proof-CTA narrative, full-sentence headline claims, and speaker notes. |
| [video-scripts](video-scripts/SKILL.md) | content | Write short-form video scripts for ads and organic: hook-retain-payoff structure, retention beats, and platform-fit formatting. |
